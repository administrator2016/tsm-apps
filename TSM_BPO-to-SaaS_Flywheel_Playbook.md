# TSM BPO → SaaS Flywheel Playbook
### Mapped onto the Tier 1/2/3 vertical rollout order

---

## 1. The Model

```
Phase 1: WE DO IT           → Lead with BPO service. "TSM takes this workload off your team."
Phase 2: WE HELP YOU DO IT  → TSM runs the work on its own platform internally.
                               TSM becomes its own first customer — discovers which
                               workflows are repetitive, where humans lose time, what
                               should become SaaS.
Phase 3: YOU DO IT WITH TSM → Client's own team gets seat access to the platform.
```

Three commercial models, offered per client based on maturity:

| Model | Client says | TSM provides | Revenue |
|---|---|---|---|
| **A — BPO Only** | "Just handle it." | People + process + platform (invisible to client) | Service/BPO fees |
| **B — BPO + Platform** ⭐ likely sweet spot | "Handle the hard work, give our team the platform." | Managed services + seat access + reporting | BPO + SaaS subscription |
| **C — SaaS Only** | "We'll run it ourselves." | Software, support, implementation | Recurring SaaS |

The BPO engagement is the **acquisition engine** for SaaS — not a separate business:

```
Free Assessment → Operational problem identified → BPO engagement →
TSM performs + learns the workflow → Client sees results →
"Can our team use this?" → SaaS subscription → Expansion
```

## 2. Mapped onto real wiring status — every vertical

The flywheel only works where Phase 1 (BPO delivery) is actually deliverable today. That's a direct function of which verticals have real exception+correction logic vs. queue-only vs. nothing. Every vertical gets slotted into the same 3-phase progression — what changes per vertical is *which phase it's able to start at*.

### Tier 1 — real exception+correction wiring (start at Phase 1 today)

| Vertical | Lead model | Notes |
|---|---|---|
| Mortgage | A → B | Deepest correction logic of the four (loan-level exception detection, financial-impact reconciliation) |
| Construction | A → B | |
| Healthcare | A → B | 5-engine denial pipeline (Doc Intel → Root Cause → Financial Impact → Recovery Plan → Navigator) is a strong Phase-1 sales narrative on its own |

**Playbook for this tier:** Lead with "we do this for you" (Model A). You're already running these war rooms/strategists/exec portals internally, so Phase 2 ("TSM as own first customer") is already happening by default — make that explicit in the pitch and start tracking which exceptions/doc types recur most, since that evidence is what justifies the Model B upsell. Once a client's seen 2–3 delivery cycles, offer seat access (Model B) to the same tooling.

### Tier 2 — queue-only wiring (start at Phase 2, pilot-scoped)

| Vertical | Lead model | Notes |

No Model C here yet — there's no mature platform experience to hand a client's team.

## 4. Who you're selling to

Not "broker vs. agency vs. individual agent." The qualifying question is:

> **Does this organization have enough outsourcable operational volume/complexity that removing part of the workflow creates measurable value?**

Applies across verticals — general contractors (Ameris), agencies/brokerages/MGAs/TPAs/carriers for Insurance, practices/billing groups for Healthcare, etc. The referral source (agent, broker, existing cleaning-company relationship) is the entry point, not necessarily the buyer.
