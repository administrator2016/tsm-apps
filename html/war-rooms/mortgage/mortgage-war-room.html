⚡ HOW TO USE — MORTGAGE COMMAND CENTER

STEP 1 — LOAD PIPELINE DATA

  • Click LOAD SAMPLE DATA to populate a realistic loan pipeline, or wire in live loan-origination records via the entity loaders.
  • RESET SAVED DATA clears the locally persisted portfolio and starts clean.

STEP 2 — WORK THE THREE ENTITY TABS

  • LOAN FILES — tracks each loan through Application → Processing → Underwriting → In Conditions → Clear to Close → Funded/Denied.
  • UW CONDITIONS — underwriting conditions correlated to a loan file by loan_id, moving Issued → Submitted → Under Review → Cleared.
  • COMPLIANCE EXCEPTIONS — flags correlated the same way, surfacing regulatory or investor-guideline breaches on a loan file.

STEP 3 — READ THE KPI BAR & STAGE TRACKER

  • KPIs surface Open Loan Files, Loans Over SLA, CTC Ready, Pipeline Value, Open UW Conditions, and Open Compliance Flags.
  • The STAGE DISTRIBUTION tracker shows volume at each pipeline stage — stages in red are past their SLA window.

STEP 4 — RUN ANALYSIS & RELAY

  • RUN AI ANALYSIS generates pipeline risk, SLA-breach root cause, and closing-readiness guidance across the open loan file portfolio.
  • RELAY TO STRATEGIST hands the current snapshot and AI findings off to the Mortgage Strategist for the next-step recommendation.
